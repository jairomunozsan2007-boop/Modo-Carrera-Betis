Copias de seguridad

Tus cambios se guardan automáticamente en este navegador. Además, descarga una copia JSON con todos los registros para poder recuperarlos en otro dispositivo o navegador.

Importante: el almacenamiento del navegador no es una nube. Exporta copias periódicamente, especialmente antes de borrar datos o cambiar de móvil.

Principios del archivo

  • No se inventan resultados ni estadísticas.
  • Los registros pueden editarse y eliminarse.
  • La clasificación debe contrastarse con el juego.
  • Las copias JSON permiten conservar el archivo.
  • Este prototipo no se sincroniza automáticamente entre dispositivos.
